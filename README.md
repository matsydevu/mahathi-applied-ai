# Mahathi — Human-centered portfolio

A standalone, responsive portfolio concept with a warm editorial visual language, interactive bookshelf, and generalized project stories. It intentionally avoids customer names, records, screenshots, and confidential details.

## Preview
Open `index.html` in a browser. The bookshelf spines are interactive.

## Publish later (optional)
Upload the four files to any static host (GitHub Pages, Netlify, Vercel, etc.). No build step is required.

The portrait references the existing public portfolio asset at `https://mdevsales.github.io/mahathi-3d/me.png`.
